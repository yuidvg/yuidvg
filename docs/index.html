企画・設計から開発・導入・運用まで

2026年8月〜現在 2026年11月終了予定

中古家具販売事業者様の社内システム整備

一点ごとに異なる中古家具を管理する業務に合わせ、GoogleスプレッドシートとGoogle Apps Scriptで業務システムを設計・実装。営業・顧客対応からデータ整理、導入、フィードバックを受けた改善まで一貫して担当しています。

取り組み・実績

貼り付けた情報から項目を自動入力し、データの矛盾を警告する機能を実装しました。Claude・GPTによる在庫回転の傾向分析や、TabFMによる販売価格・売上の予測処理も導入しています。

入力ご担当者様から入力の負担が減ったとの評価を得ました。予測結果は仕入れご担当者様が最終確認する判断材料とし、実際の仕入れ判断での利用はこれからの段階です。

Google Apps Script / Googleスプレッドシート / Claude / GPT / TabFM

2025年9月〜2026年5月

AIを活用した合意形成システム

AIが生成するYes／No形式の質問を通じて、会議参加者の意見の相違や対立点、関心が向けられていない論点を抽出するシステムを3名で共同開発しました。チーム開発をリードし、仕様整理、コードレビュー、タスク分担、追加機能開発、リデザインを担当しました。

取り組み・実績

CI/CD、ステージング環境、Sentryによる運用監視を導入。Nix・Colmenaによる環境構築・デプロイの整備や、自動テストと型安全性を用いた重要な処理の安定化にも取り組みました。

1,000人以上が利用し、大企業様での導入1件、4自治体様での利用実績があります。

Next.js / Supabase / Gemini / Vercel / Nix / Colmena / Sentry / Haskell

プロフィール

2001年生まれ。大阪府出身。2019年から個人事業主として、Webサイト制作、資料翻訳、プログラミング教育、アプリ開発に取り組んでいます。2025年9月から合同会社多元現実で活動し、2026年1月に社員に就任しました。

業務アプリでは、お客様と要件を整理し、画面設計、技術選定、開発チームの採用、プロジェクト管理、導入支援を担当してきました。AI合意形成システムの機能開発と本番運用基盤の整備も経験しました。現在は中古家具販売事業者様の業務システムを設計・実装し、導入と改善を進めています。

幼少期から科学、写真、絵画に親しんできました。登山と歴史にも関心があります。クライミングやギターも楽しんでいます。
