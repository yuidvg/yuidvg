Toubans!：LINEで当番を設定・通知する

2018年採択・受賞／2019年ファイナリスト選出

高校時代に、掃除当番などの設定・通知をLINE上で行うサービスを開発しました。

LINE個人開発

身近な当番の連絡をLINEにまとめる

学校での当番の任命や通知をLINE上で行えるサービスを開発しました。掲載画像は、Botを友だちに追加し、グループへ招待してフォームから通知内容を設定する流れを示しています。

利用者の反応を受けた改善

未踏ジュニアのプロジェクト紹介では、利用者のフィードバックをもとに改善を進め、ユーザーがBotを作成できるシステムの開発に取り組んだことが紹介されています。

採択・受賞

2018年度未踏ジュニアに採択され、スーパークリエータに認定されました。LINE BOOT AWARDS 2018ではグランプリ・学生部門賞を受賞しました。

2019年にはSXSW EDUのStudent Startup Competitionでファイナリストに選出されました。
