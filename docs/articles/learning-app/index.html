学習塾様向け学習支援アプリ

2020年10月〜2024年7月

生徒自身が目標設定や学習計画づくりに参加できるアプリを開発。営業・企画、採用、顧客対応、技術選定、要件整理、画面設計、デザイン、導入を担当し、実装・テストは採用したエンジニアが担当しました。

FlutterFirebaseFigma

生徒自身が計画づくりに参加する

学習塾様が学習計画を示し、声をかけるだけでは学習が継続しにくい状況を受け、生徒自身が目標設定や学習計画づくりに参加できるアプリを開発しました。

企画・設計から導入まで

営業、企画、採用、顧客対応、技術選定、要件整理、画面設計、デザイン、導入を担当しました。実装・テストは採用したエンジニアが担当しました。

学習内容・達成目標に応じたカレンダーへの予定の自動配分、実施記録、ゲーミフィケーションを設計しました。忘却曲線を参考にした学習スケジュールと、累計・月別の学習時間を確認できるダッシュボードを取り入れました。

利用実績

200名以上の生徒が利用しました。ダッシュボードで自分の努力を確認できることが自信につながり、次の学習にも前向きに取り組めるようになったとの声を得ました。
